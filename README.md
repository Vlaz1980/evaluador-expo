# Evaluador Expo Software 2026-2

App web para evaluar los proyectos de la XXIII Feria Tecnológica Expo Software (UPC) con la rúbrica de la actividad (fichas A, B y C, criterios C1–C8).

**Abrir:** https://vlaz1980.github.io/evaluador-expo/

Funciona en Chrome (Android o PC). Los datos se guardan en el navegador (SQLite); el informe se genera en PDF y se envía por correo.
